# Security policy

## Supported versions

TorchGAMLSS is alpha software. Security fixes are applied to the current
development branch and, when appropriate, the latest `0.1.x` pre-release.
Older snapshots are not supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or for information
that could expose credentials, private data, or an exploitable weakness.
Use GitHub's private vulnerability-reporting form:

https://github.com/martinoni/torchgamlss/security/advisories/new

Include a description, affected versions, reproduction steps, potential
impact, and any suggested mitigation. The maintainer will acknowledge a
report as soon as practical, investigate it privately, and coordinate
disclosure after a fix is available.

Statistical disagreements, convergence failures, and numerical parity issues
without a security or privacy impact belong in the public bug tracker.
